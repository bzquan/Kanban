# Kanban SPA — 手動受け入れチェックリスト (2026-11-13)

Playwright は未導入のため、jsdom で検証できない UI 挙動(dnd の感触、DragOverlay、画面適応)は
人間による確認で締める。対象: `feat/kanban-web-backend` ブランドの SPA(タスク12時点)。

**Setup**: `cd frontend/app && npm run build`; `dotnet run --project Kanban.Api`
(注意: appsettings は本番想定の DB を指す — 192.168.21.150/`kanban`。テスト用姿勢で実行すること);
ブラウザで `http://localhost:5000/` を開く。

1. **ボード開き**: ボード一覧が表示される。ボードを開くと URL が `/boards/<id>`。
   ディープリリンクでリロード → 404/空白でなくボードが描画される(SPAフォールバック動作)。
2. **列をまたぐドラッグ**: カードを列1のWIPから列2へドラッグ → ドロップインジケーターが出た後
   その列にカードが表示される。リロード → 永続化。活動ログにも記録。
3. **空サブ列へのドロップ**: 空のWIP/Doneサブ列へドラッグ → ドロップ受理、正しい位置に着地。
   リロード → 永続化。
4. **ドラッグ最中のEscape**: ドラッグ開始後にEscape → ドラッグ中止、カードの**複製/クローンが
   どの列にも残っていないこと**(元列・先方列を確認後リロード)。
5. **バックボード移動**: カードをバックボード(step 0 / backlog)へ、再び作業列へ。
   両方向ともリロード後に永続化。
6. **5種のチャートすべて**: ボードページで Chart 切替 → 全5種(累積フロー・サイクルタイム・
   スループット・バグ/ブロック・ベロシティ)が座標軸+系列を描画、コンソールエラーなし。
7. **EN→JP→ZH 全文字列切替**: 設定で言語を切ると、表示中の全文字列(nav・列見出し・ボタン・
   チャートタイトル・空状態)が切り替わる(意図的な固有名詞を除く)。リロード → 言語が保持される。
8. **2タブ整合**: 同じボードを2タブで開く。タブAでカード作成/編集/削除 → タブBをリロードで
   タブAの状態になる(キャッシュ由来の乖離がないこと)。
9. **カードCRUD**: 作成 → タイトル/ストーリーポイント編集 → 削除。各ステップが即座かつ
   リロード後も反映される。

完了後: 5項目のレビューフォーカス(同時編集整合・無効ID・ドロップ指標・生のi18nキー非表示・
空データチャート)も目視確認済みとして報告すること。
